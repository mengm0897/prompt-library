# Prompt 管理器视觉基准

> 2026年10月14日经可交互 HTML 原型体验确认。原型是本机 `设计原型/视觉方向A-阅读型卡片.html`，不进入公开仓库；本文是公开工具的长期设计事实来源。

## 方向与边界

- 主方向是安静的浅色工作台：左侧分类，右侧先筛选、再看卡片、最后阅读正文。卡片陈列保留。
- 淡紫、浅蓝、亮黄各有职责：淡紫标识当前分类与顶部两个平行入口，浅蓝用于阅读链接和保存等完成动作，黄色用于品牌标记与历史参考。长正文维持白底深色文字。
- 本轮只改变布局、样式、文案层级和操作入口；新增、编辑、分类迁移、删除、备份的请求与数据规则保持不变。

## 共同层级

| 层级 | 元件 | 规则 |
|---|---|---|
| 页面级 | 首页标题 | 26–34px，页面只出现一次 |
| 弹窗主标题 | 详情、编辑、管理分类 | 22–25px，压过内部区域标题 |
| 区域级 | 结果标题、分类页“大类／子类” | 18px；两栏共用一套标题行，标题和新增按钮顶端对齐 |
| 内容级 | 卡片标题、表单文字 | 卡片标题18px，正文及操作14px左右；长标题可换行 |
| 辅助级 | 分类、数量、状态、说明 | 12–13px；颜色退后，仍可辨认 |

间距使用 `--space-*`，颜色与字号使用 `:root` 中的语义变量。新增组件先复用已有层级，确有新职责时才增加变量；不按字段单独堆样式。

## 组件和行为

- **顶部入口**：“管理分类”和“新增 Prompt”同等视觉权重，都用方案2的淡紫填充、相同高度、边框、圆角与轻阴影。弹窗内的保存操作仍可使用蓝色完成按钮。
- **筛选栏**：搜索优先占宽；所有下拉框使用统一箭头与右侧留白，不靠浏览器默认箭头碰边。筛选在窄屏换行，入口可见。
- **提示词卡片**：桌面两列、窄屏一列；标题、最多两行摘要、分类与必要状态依次排列。卡片形状、内边距、悬停和键盘聚焦共用规则。
- **详情阅读**：分类和标题先交代位置，阅读／原文采用底部线条的平行切换；正文为白底阅读区。删除入口退后并保留单独确认，复制原文是主要完成动作。
- **分类管理**：左栏只管理大类，右栏只管理当前大类的子类。两栏标题是同一字号、同一行高的“大类／子类”；“新增大类／新增子类”是相同按钮。左栏选中大类有淡紫底纹；大类重命名／删除位于对应行内，子类重命名／删除位于各自容器右侧。图标有文字提示与无障碍名称；点删除后仍经过现有迁移或确认流程。子类多时右栏独立滚动，不产生贯穿整页的操作列。
- **表单与反馈**：标签说明字段，提示只解释后果；操作名称在按钮、确认和反馈中保持一致。危险动作使用独立危险色。输入框、下拉框和按钮共用焦点规则。

## 验收场景

使用公开虚构示例或隔离副本检查：首页分类与筛选、两列卡片和窄屏单列；长标题与长正文；详情阅读／原文；新增和编辑；分类多子类情况下的大类／子类新增、重命名、删除入口；删除确认、备份入口与键盘聚焦。正式功能不能因视觉改动改变接口路径或私人数据。

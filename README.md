# Prompt 库

一个在自己电脑上运行的提示词资料库。用浏览器查看、搜索、分类和编辑提示词；正文保存为独立 Markdown 文件，SQLite 用于网页检索。不需要账号、联网或第三方 Python 包。

想先看清第一版的功能和数据结构，可读 [MVP 功能与结构](docs/MVP功能与结构.md)。

## 启动

需要 Python 3.10 或更新版本。在本目录打开终端，运行：

```sh
python3 app/server.py
```

在浏览器打开终端显示的 `http://127.0.0.1:8765`。关闭终端里的服务进程即可停止。默认只监听本机地址，不会主动上传提示词。

全新副本首次启动时会创建分类词表、SQLite 索引，并把 `examples/` 中的两条**虚构示例**复制到个人的 `prompts/`。示例可直接编辑或归档。已有 `prompts/` 或数据库的使用者不会被重新加入示例；服务会从已有 Markdown 建立或更新索引。

## 添加和找回自己的提示词

1. 点击网页的“新增提示词”，填写标题、分类和正文，再保存。也可以选取 `.md` 或 `.txt` 文件，将内容载入表单后保存；原文件不会被修改。
2. 保存后，正文写入 `prompts/0001.md` 等独立文件，并更新 `data/prompts.sqlite3`。关闭浏览器或重启服务后，仍可从本机文件读回。
3. 用网页上方搜索框及分类、子类、标签筛选查找。点击卡片可阅读、复制、编辑、归档或恢复。

每份 Markdown 顶部的 `---` 区域存放标题、分类等元数据；下面是正文。可以直接编辑 Markdown，网页约5秒内读取更新。请不要随意修改文件名或 `id`；字符串需保留双引号，标签使用 JSON 数组。

分类词表在 `data/taxonomy.json`。网页左侧“管理大类与子类”可以新增分类；重命名、合并和删除尚不支持直接在网页操作。直接编辑 Markdown 时，分类必须先存在于词表中。

## 备份与附件

网页“导出备份”得到的 JSON 包含所有提示词正文，属于你的私人数据。请自行安全保存；网页“导入备份”可将其中的条目导入，重复条目会跳过。也建议定期备份 `prompts/`、`data/taxonomy.json` 和自己的附件。SQLite 是检索索引，不应作为唯一备份。

如需在正文中引用本机图片或 PDF，可把文件放在 `图片和附件/`，正文使用 `图片和附件/文件名`。详情页会展示或链接这些附件。公开示例不包含附件；使用者添加的附件应按自己的公开范围管理。

## 文件说明

| 路径 | 用途 |
|---|---|
| `app/` | 本机 Python 服务与网页 |
| `examples/` | 随工具提供的两条虚构示例 |
| `prompts/` | 使用者自己的正式 Markdown 数据 |
| `data/taxonomy.json` | 使用者的分类词表 |
| `data/prompts.sqlite3` | 自动生成的本机检索索引 |
| `图片和附件/` | 使用者自行加入的本机附件 |

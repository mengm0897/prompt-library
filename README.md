# Prompt 管理器

一个在自己电脑上运行的 Prompt 管理工具。用浏览器查看、搜索、分类和编辑 Prompt；正文保存为独立 Markdown 文件，SQLite 用于网页检索。不需要账号、联网或第三方 Python 包。

想看清当前功能和数据结构，可读 [MVP 功能与结构](docs/MVP功能与结构.md)。
界面的字号、间距、卡片与文案约定见 [界面组件与文案规则](docs/界面组件与文案规则.md)。
经本人确认的视觉方向与验收范围见 [视觉基准](docs/视觉基准.md)。

## 启动

需要 Python 3.10 或更新版本。在本目录打开终端，运行：

```sh
python3 app/server.py
```

在浏览器打开终端显示的 `http://127.0.0.1:8765`。关闭终端里的服务进程即可停止。默认只监听本机地址，不会主动上传提示词。

全新副本首次启动时会创建分类词表、SQLite 索引，并把 `examples/` 中的两条**虚构示例**复制到个人的 `prompts/`。示例可直接编辑、归档或删除。已有 `prompts/` 或数据库的使用者不会被重新加入示例；服务会从已有 Markdown 建立或更新索引。

## 添加和找回自己的提示词

1. 点击网页的“新增 Prompt”，填写标题、分类和正文，再保存。也可以选取 `.md` 或 `.txt` 文件，将内容载入表单后保存；原文件不会被修改。
2. 保存后，正文写入 `prompts/0001.md` 等独立文件，并更新 `data/prompts.sqlite3`。关闭浏览器或重启服务后，仍可从本机文件读回。
3. 用网页上方搜索框及分类、子类、状态筛选查找。点击卡片可阅读、复制、编辑、归档、恢复或删除。

每份 Markdown 顶部的 `---` 区域存放标题、分类等元数据；下面是正文。可以直接编辑 Markdown，网页约5秒内读取更新。请不要随意修改文件名或 `id`；字符串需保留双引号。

分类词表在 `data/taxonomy.json`。网页右上角“管理分类”可以新增、重命名、删除大类和子类。删除正在使用的分类时，先选择迁移目标；已有提示词会随之改到目标分类。直接编辑 Markdown 时，分类必须先存在于词表中。

在详情页删除提示词需再次确认；确认后会永久删除该条 `prompts/编号.md`，并从 SQLite 索引移除。删除不会影响其他提示词或 `图片和附件/` 中的文件。需要找回时只能使用删除前保存的备份。

从旧版升级时，建议先备份自己的 `prompts/` 和 `data/`。新版首次读取会把旧 Markdown 中的标签、来源、备注字段移除并重建 SQLite 索引，提示词正文不变；旧版 JSON 备份仍可导入，旧字段会被忽略。

## 备份与附件

网页“导出备份”得到的 JSON 包含所有提示词正文，属于你的私人数据。请自行安全保存；网页“导入备份”可将其中的条目导入，重复条目会跳过。也建议定期备份 `prompts/`、`data/taxonomy.json` 和自己的附件。SQLite 是检索索引，不应作为唯一备份。

如需在正文中引用本机图片或 PDF，可把文件放在 `图片和附件/`，正文使用 `图片和附件/文件名`。详情页会展示或链接这些附件。公开示例不包含附件；使用者添加的附件应按自己的公开范围管理。

## 文件说明

| 路径 | 用途 |
|---|---|
| `app/` | 本机 Python 服务与网页 |
| `examples/` | 随工具提供的两条虚构示例 |
| `prompts/` | 使用者自己的正式 Markdown 数据 |
| `data/taxonomy.json` | 使用者的分类词表 |
| `data/prompts.sqlite3` | 自动生成的本机检索索引 |
| `图片和附件/` | 使用者自行加入的本机附件 |
